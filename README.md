# CalculatorPro 功能使用手册

CalculatorPro 用于课程目标达成度计算、统计表与分析报告生成，并提供教学大纲整理、教学日历、课程教案、课表和教师资料管理。

本文对应 2026-10-15 的线上功能。普通教师使用教师端，课表、教师资料、邀请码和 API 配置由管理员维护。

## 访问入口

| 使用者 | 入口 | 用途 |
| --- | --- | --- |
| 教师 | [教师端](https://calc.geekhuang.com/) | 课程、大纲、成绩、达成度报告、教学日历和教案 |
| 管理员 | [管理后台](https://calc.geekhuang.com/admin/) | 概览、用户、任务、课表、教师资料、邀请码及设置 |

教师账号与管理员账号分别登录。手机使用管理后台时，可从右上角“菜单”切换页面。

## 第一次使用

1. 向管理员或已有用户获取有效邀请码，在登录页选择“注册账号”。填写用户名或邮箱、至少 8 位密码及邀请码。
2. 登录教师端，点击“从大纲建课”，上传课程教学大纲。
3. 核对课程信息、课程目标和考核对应关系，确认建课。
4. 按需要选择以下流程。

| 你要完成的工作 | 建议操作顺序 |
| --- | --- |
| 生成达成度分析报告 | 从大纲建课 → 导入成绩登记表 → 检查与修改 → 生成报告 |
| 只计算结果或导出统计表 | 准备课程与成绩 → 高级选项 → 只计算达成度 / 只导出统计表 |
| 编制教学日历 | 从大纲建课并确认课次 → 教学日历 → 核对教师 → 下载 `.xls` |
| 编制课程教案 | 保存原始 Word 大纲 → 课程教案 → 核对封面 → AI 生成教案 → 修改 → 确认生成 Word |

如果暂时没有大纲，可以选择“新建空白课程”，再展开“检查与修改”手动填写课程信息。教学日历和教案还需要相应的课次资料。

## 教师端使用

### 1. 从大纲建课或更新大纲

1. 点击“从大纲建课”，选择 `.docx` 或能够复制文字的 PDF，单个文件不超过 5 MB。
2. “允许 AI 纠错与补全”默认开启。旧版格式、缺项或矛盾内容会进入可编辑草稿；不希望补全时可以取消勾选。
3. 点击“读取大纲”，等待进度完成。已经读取过的资料，可使用“继续查看上次读取结果”；已有原始大纲的课程可选择“补全当前课程已保存的大纲”。
4. 逐项核对课程名称、学院、学分、总学时、课程简介、课程目标、毕业要求以及考核对应关系。AI 补充的内容需结合实际教学确认。
5. 修改后点击“重新校验”，按提示处理目标引用、支撑关系、权重和学时问题，再点击“确认建课”。
6. 遇到已有同名课程时，核对提示后选择“用新大纲更新”，避免重复建课。

课程目标编辑上限为 8 个。旧 `.doc` 请先在 Word 中另存为 `.docx`；扫描件或图片 PDF 请改用 Word 版或带文字的 PDF。后续要生成课程教案时，建议直接使用包含课次表的原始 `.docx` 大纲。

大纲版本按课程保存，成绩和结果按学期保存。更新大纲后，请留意首页提示的当前学期所用大纲版本。

### 2. 导入成绩并生成达成度报告

1. 在“已有课程”中选择课程。
2. 点击“导入成绩登记表”，选择 Excel（`.xlsx` / `.xls`）、Word（`.docx`）或 PDF。核对识别出的学年学期、教师、班级及成绩，再确认导入。
3. 在“学期”中确认本次分析使用的学期。
4. 展开“检查与修改”，按以下项目核对资料。

| 项目 | 重点检查 |
| --- | --- |
| 开课信息 | 课程名称、开课部门，以及当前学期的教师、班级、专业和人数 |
| 课程基本信息 | 课程性质、课程简介和课程目标等 |
| 成绩占比 | 各考核环节的比例是否与大纲一致 |
| 课程考核与课程目标对应关系 | 考核环节、方法、目标分配及权重 |
| 课程目标与毕业要求的对应关系 | 课程目标支撑的毕业要求及其说明 |
| 设置 | 生成报告所需的其他课程设置 |

5. 确认页面显示“已保存”后，点击“生成报告”。
6. 在进度窗口中查看排队和生成状态，完成后点击“下载报告”。生成的资料也可在“课程资料”中再次下载。

如果进度窗口关闭，可通过首页的任务提示重新查看。等待中的任务不要连续重复提交；失败时先按提示修正资料，再重试。

成绩分析使用所选成绩学期；教学日历和教案的教师、班级另按备课学期的课表或手填信息确定。

### 3. 高级选项：模板、正向与逆向模式

展开“高级选项”后，可以选择模式、下载成绩模板、导入文件、设置分数跨度、分布模式、噪声及报告风格。

- **正向模式**：根据已填写的考核方法级成绩计算达成度。先确认对应关系表，再下载模板、填入成绩并通过“导入文件”上传 `.xlsx`。
- **逆向模式**：根据考核环节总分和所选参数推算方法级分数。先完成对应关系表，再下载逆向模板、填写和上传；生成后核对推算明细。
- **只计算达成度**：计算并查看结果，不调用 AI。
- **只导出统计表（不调用 AI）**：下载成绩统计和达成度相关资料，不生成 AI 分析文字。
- **生成报告**：生成包含分析文字的报告，需要服务器可用的 AI 配置。

对应关系表支持直接编辑，也支持从 Excel 复制后粘贴：先点击起始单元格，再粘贴。请使用当前模式和当前关系表生成的模板，不要混用正向、逆向模板。

需要比较上一学年结果时，可在相应区域导入上一学年达成度 `.xlsx` 文件，并核对其课程目标是否对应。

### 4. 生成教学日历

1. 先通过“从大纲建课”保存包含课次、章节、教学内容及学时的资料。
2. 选择课程，点击“教学日历”。
3. 如提示课表中的课程名称不同，先核对并选择对应课程；也可按提示选择“不关联，继续生成”。
4. 如同一课程对应多位教师，选择本学期教师，再点击“确认本学期教师并生成”。教师选择只在本课程、本学期沿用，新学期需要重新确认。
5. 等待文件生成。系统会尝试自动下载；浏览器未自动保存时，点击“下载 .xls”。
6. 打开文件，核对学年学期、教师、班级、课次、学时和签字栏。

主页面输出学校模板的 `.xls` 文件，下载时使用已保存的课次内容，不再次调用 AI。学时列为数字，便于继续统计。

教学日历按下载当天的北京时间确定学年学期：9 月至次年 1 月为第 1 学期，2 月至 8 月为第 2 学期。它不直接沿用成绩分析当前选中的历史学期。进度达到 100% 表示文件已生成并可下载，请同时确认浏览器的下载结果。

### 5. 生成和修改课程教案

1. 选择课程，点击“课程教案”。系统会载入已保存的大纲和教案草稿。
2. 首次没有原始 Word 大纲时，选择包含课次表的 `.docx`（不超过 5 MB），点击“上传大纲并继续”。
3. 核对课程名称、学年、学期、授课教师、授课对象和教研室。有多位教师时，先选择实际授课教师。
4. 如果后台课表没有对应信息，点击“改为手动填写”；教师、授课对象和教研室也可以留空，下载后在 Word 中补填。需要重新使用课表信息时，点击“恢复使用后台课表”。
5. 点击“AI 生成教案”，等待各课次生成。任务会保存进度，关闭窗口后可再次打开查看。
6. 使用课次选择框或“上一课次 / 下一课次”，检查并修改四栏内容，以及学习资料、学习网站和课程评价。
7. 点击“保存修改”。需要核对排版时点击“检查页数”；超页课次可以先手动精简，再按需使用“压缩这一课次”。
8. 点击“确认生成 Word”，完成后使用“下载 Word”。

四栏建议字数如下，页面会显示实际字数及是否超出范围：

| 栏目 | 建议字数 |
| --- | --- |
| 教学目标或要求 | 120–180 字 |
| 教学内容 | 220–300 字 |
| 教学手段与方法 | 100–150 字 |
| 思考题、讨论题、作业 | 50–80 字 |

**导出格式：每个课次表格的授课题目、课次数字、授课类型、授课学时和正文，统一为仿宋_GB2312、小四（12 磅）。封面沿用原模板格式。**

已有正文只需重新导出或应用最新字体格式时，直接点击“确认生成 Word”，不必再次点击“AI 生成教案”。“确认生成 Word”和“检查页数”不调用 AI；“AI 生成教案”和“压缩这一课次”会调用 AI。

修改正文、封面或学期后，应重新生成 Word；旧文件不会自动更新。服务器页数检查使用服务器字体，最终字体和分页以本机 Word 打开后为准，电脑需安装仿宋_GB2312。

### 6. 教师、班级和教研室怎样填写

- 课表匹配按课程、学年、学期进行。名称不同但页面给出候选时，应先确认对应课程。
- 教师与班级优先使用后台已核对的本学期课表；多位教师时由本人选择。
- 教研室从教师资料库关联，通常使用所属系去掉末尾的“系”。存在同名或资料缺失时，请核对后手填或联系管理员。
- 教案内保存的手填授课信息只用于当前课程、当前学期的教学日历和教案；后台课表更新不会覆盖已确认的手填值。
- 不要把“当前成绩分析学期”和“当前备课学期”混为一谈。需要生成其他学期教案时，请在教案封面核对并修改学年和学期。

### 7. 保存、下载和账号管理

课程信息会自动保存，请在切换页面前留意“已保存”状态。课程资料保存在账号下，更换电脑后登录同一账号可以继续查看。

在“课程资料”中，可按学期下载资料包、单个文件、导入资料和模板，也可展开“查看历史版本”下载旧版本。删除历史版本前应核对所属学期和文件；“删除课程”会删除该课程的所有学期、成绩及报告，程序内无法恢复。

页头“我的邀请码”可查看和复制个人邀请码，剩余次数及状态以页面为准。“修改密码”需要填写当前密码和新密码。账号在其他设备重新登录后，旧页面可能提示会话已更新，请按提示重新登录。

## 管理员端使用

### 1. 先配置 AI API

进入[设置](https://calc.geekhuang.com/admin/settings)，选择“沿用服务器配置”或“填写独立密钥”，核对模型名称，点击“测试连接”，再点击“保存配置”。

设置用于课程大纲读取、教学日历内容整理及 PDF 课表识别等流程。教师端无需输入密钥。独立密钥保存后不回显，再次保存时留空表示保留原密钥。

“测试连接”只验证认证和模型列表，不生成教学内容，也不检查余额。报告生成使用的服务器配置由运维维护；后台设置不会直接覆盖其环境配置。

### 2. 导入、核对和查询课表

1. 进入[课表管理](https://calc.geekhuang.com/admin/schedule)。
2. 上传学校公布的带文字 PDF，单份不超过 8 MB、1–15 页；扫描件需先换成能够复制文字的版本。
3. 点击“开始识别”，等待后台任务完成。关闭弹窗后任务仍会继续，可从页面的待处理项查看进度或结果。
4. 在识别结果中核对学年学期、课程名称、教师、班级和教学周次。需要修改的记录选择“核对 / 修正”。
5. 确认后点击“保存到课表库”。
6. 通过搜索、学期及核对状态筛选查询记录。重复上传同一 PDF 会复用已有草稿或提示已入库。

要让教师端自动填写本学期授课信息，需要先导入对应学年学期的课表，并完成必要的教师、班级核对。

### 3. 删除与恢复课表

课表页面支持三种删除范围：

| 操作 | 范围 |
| --- | --- |
| 删除已选 | 勾选的开课记录；“全选当前筛选结果”只选择当前筛选结果 |
| 删除某份 PDF | 该导入文件对应的开课记录 |
| 清空所选学期 | 该学期全部课表记录，包括被搜索或状态筛选隐藏的记录 |

确认删除前检查记录数、学期和文件名称。删除后可在“最近删除”中点击“恢复”，需要时加载更早记录。

删除课表不会删除用户课程、大纲、成绩、教师目录或已生成教案内容。后续生成会重新查询课表；授课信息变化时，需要重新确认导出。若同一 PDF 已经重新导入，恢复旧删除记录可能被拒绝，以避免覆盖新数据。

### 4. 维护教师资料

1. 进入[教师信息](https://calc.geekhuang.com/admin/teachers)。
2. 选择不超过 5 MB 的带文字教师联系表 PDF，点击“读取并预览”。
3. 核对姓名、所属学院、所属系、教研室、联系方式及处理方式。同名记录需要明确选择新增、更新或跳过及对应人员。
4. 点击“确认导入”。列表支持按姓名、系、教研室或电话搜索，以及按启用状态筛选。
5. 少量资料可通过“手动新增”或“查看 / 编辑”维护；不再使用的教师可“停用”，需要时再“启用”。

未出现在新联系表中的旧教师不会被自动删除。行政分组或所属系不明确的人员，请人工维护教研室。联系方式和原文依据仅管理员可见，教师端只使用与授课信息关联的姓名和组织信息。

### 5. 邀请码、用户和任务

- [邀请码](https://calc.geekhuang.com/admin/invites)：创建邀请码、调整可注册次数、启停或删除。注册成功后才消耗次数；实际额度以后台为准。
- [用户](https://calc.geekhuang.com/admin/users)：查看教师账号、课程、邀请来源及使用概况。
- [任务](https://calc.geekhuang.com/admin/jobs)：查看页面提供的实时任务与报告历史，可按用户筛选并翻页，每页 10 条。
- [概览](https://calc.geekhuang.com/admin/)：查看使用与运行统计。

## 文件格式速查

| 用途 | 接受的输入或输出 |
| --- | --- |
| 从大纲建课 | `.docx` 或带文字 PDF，最多 5 MB |
| 教案原始大纲 | `.docx`，最多 5 MB，需包含课次表 |
| 导入成绩登记表 | `.xlsx` / `.xls` / `.docx` / `.pdf`，以页面校验结果为准 |
| 高级选项的成绩文件、上一学年达成度 | `.xlsx` |
| 后台课表 PDF | 带文字 PDF，最多 8 MB、1–15 页 |
| 教师联系表 PDF | 带文字 PDF，最多 5 MB |
| 教学日历下载 | `.xls` |
| 课程教案下载 | `.docx` |
| 统计与报告 | ZIP 资料包及其中的 Excel / Word 文件，以实际下载结果为准 |

## 常见问题

| 情况 | 处理方式 |
| --- | --- |
| 提示邀请码无效或次数不足 | 核对 6 位邀请码；联系管理员确认剩余次数与启用状态。已有账号直接登录。 |
| `.doc` 或扫描 PDF 无法读取 | 将 `.doc` 另存为 `.docx`；改用可复制文字的 PDF 或 Word 原稿。 |
| 大纲读取后内容不准确 | 在草稿中修改，重新校验后再确认；尤其检查 AI 补全的目标、权重与学时。 |
| 教学日历提示没有课次资料 | 用包含课次表的大纲重新“从大纲建课”，核对并确认保存。 |
| 找不到教师、班级或教研室 | 核对课程及学年学期；联系管理员补齐课表和教师资料，或在教案中改为手填。 |
| 教案文字还是旧字体 | 点击“确认生成 Word”重新导出并打开新文件，确认本机已安装仿宋_GB2312。 |
| 教案超过一页 | 精简该课次正文，必要时“压缩这一课次”；最后在 Word 中核对分页。 |
| 文件已生成但没有下载 | 点击弹窗中保留的下载链接，检查浏览器下载列表或下载拦截提示。 |
| 提示 AI 未配置、失败或等待 | 联系管理员检查配置，按进度提示等待或重试；只计算和只导出统计表仍可使用。 |
| 提示其他窗口修改了相同内容 | 按冲突窗口选择使用已保存的内容，或保留本页修改；避免同时编辑同一课程。 |
| 修改后下载内容没有变化 | 先保存修改，再重新生成对应 Word、统计资料或报告；已下载旧文件不会自动更新。 |
