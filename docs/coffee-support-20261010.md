# 2026-10-10 微信自愿赞助入口

按用户要求增加“请服务器喝杯咖啡 ☕”，用于自愿支持服务器运行。只展示微信；先使用明确标注“示例，暂不能付款”的图片，之后替换真实收款码。

## 界面

- 报告生成成功后的弹窗中，在“下载报告”下方显示一个绿色小文字按钮。排队、处理或失败时不显示此入口，下载报告仍为主操作。
- 页面底部保留同样的小入口。赞助弹窗由老师点击后打开，使用现有米白和绿色配色、小服务器图案以及一张居中的微信图片。
- 说明金额随意、完全自愿，不赞助也能正常使用。没有付款确认接口、支付订单、自动扣费或收到款项的提示。
- 示例图可保存；正式收款码的保存链接供手机用户在微信中识别。只读取本网站指定目录内的图片，不加载外站收款图片。
- 收款配置或图片无法读取时隐藏入口，不阻塞课程、计算和报告。关闭方式沿用已有弹窗：关闭按钮、× 或 Esc，点击外侧不关闭。

## 替换微信收款码

将准备公开展示的微信收款码图片放在 web_app/static/support/wechat.png，保持图片中的二维码完整、清晰。也支持 .jpg、.jpeg、.webp，不需要改变课程或数据库。

然后编辑 web_app/static/support.json：

```json
{
  "preview": false,
  "wechat": "/static/support/wechat.png"
}
```

完成部署并刷新页面后，图片与按钮文案会自动切换为正式微信收款码。没有真实收款码时保持当前 preview=true 的示例配置；若需要关闭整个入口，将 wechat 改为空字符串。不要把密钥或账号密码放进此文件，它是网页可读取的静态配置。

web_app/static/index.html、app.js、style.css：入口、弹窗、显示条件、下载链接与自适应样式；web_app/static/support.json：示例配置；web_app/static/support/example.svg：不含有效支付码的示例图片；本说明文档。

没有修改 main.py、ui_app/、core_app/、数据库、成绩导入逻辑、达成度公式、期望值规则或表 5。
