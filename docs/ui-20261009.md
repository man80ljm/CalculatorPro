## 兼容边界

新生成的报告保存实际输入指纹和摘要，可以跨设备恢复，能识别设置改动、文件替换和输入恢复；空字段、派生合计或行表头补全不会被视为内容改动。相同成绩文件原字节重复上传也不会使新报告过期。失败的新任务不会隐藏已成功的旧报告；任务临时输入清理后仍保留报告状态与摘要。

升级前的报告没有输入指纹时，仍显示已生成且可以下载；升级后的修改会被记录。无法判断这类旧报告在升级之前是否已修改过输入，也不能补出已丢失的历史摘要。后续重新生成一次后即可采用完整判断。

本批无需数据库结构迁移，不自动重新调用 AI，不自动覆盖或删除旧报告；生成新版报告仍由老师点击。
