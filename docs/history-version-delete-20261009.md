# 2026-10-09 历史资料版本删除

本批按用户截图增加历史版本的“删除这一版”，并适配手机。**本地已完成，尚未部署线上。**

## 老师看到的操作

- 展开“查看历史版本”，每个旧版本有“删除这一版”和“下载这一版”。每个学期的最新资料包继续保留，不提供删除按钮，服务器也会拒绝删除最新版。
- 删除前弹窗显示课程、学期、版本及生成时间，明确压缩包和该版文档的删除后果。默认焦点在“暂不删除”；取消、Esc 和误触弹窗外不会删除。
- 删除期间锁定按钮和确认框，避免重复操作；失败在框内提示并允许重试。成功后更新数量、保留历史栏目展开状态；删除最后一个历史版本后移除该栏目。
- 原始成绩、上一轮达成度、其他学期、其他版本、开课信息、计算摘要和自动读取上一学期的数据保持不变。
- 老版本没有文档归属信息时，只删除压缩包，单独保存的文档继续保留；被其他版本引用的共享文档也保留。
- 手机操作按钮高度至少 44 像素，两个按钮排列在版本说明下方；确认框随内容收紧，内容过长时滚动且保留操作按钮。

## 文件与实现

- `web_app/static/app.js`：历史按钮、确认及删除交互、失败重试、资料列表和状态刷新。
- `web_app/static/index.html`：删除历史版确认弹窗及资料说明。
- `web_app/static/style.css`：操作按钮及手机确认框布局。
- `web_app/app.py`：`DELETE /api/courses/{course_id}/materials/{archive_id}?confirm=1`，沿用账号会话、用户写入锁和课程版本头校验。
- `web_app/course_materials.py`：保护本学期最新包，核对归属，确定可删除的批次文件，保留共享文件和任务统计。
- `web_app/storage.py`：文件先暂存，数据库事务失败时恢复，提交成功后清理暂存；异常清理情况记录日志。
- `tests/test_material_version_delete.py`：11 个新增回归用例。
- 本文：改动及验证记录。

先移除批次及任务的外键引用，再删除文件记录，避免外键级联和 ORM 重复删除同一批次。历史任务的下载指针清空，删除后的下载返回不存在，任务统计保留。没有新增数据库结构或依赖，没有修改桌面版、达成度公式、期望值规则和表 5 的生成逻辑。
